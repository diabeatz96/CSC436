# Project1 - Restaurant Page

A responsive menu built with HTML, CSS, Bootstrap, and JavaScript. Browse sandwiches, appetizers, rice boxes, and beverages, and filter the menu by category.

# How To Run locally

1. Clone the repo:
   ```bash
   git clone https://github.com/joshcaili/CSC436.git
   cd CSC436
   ```
2. Open `index.html` in your browser
